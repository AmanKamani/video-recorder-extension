For each website tab: select its playlist, click Inject Player, play the temporary video, then start recording. You can switch tabs and start other recordings; existing recordings continue independently. Each recording writes WebM chunks directly to the file you choose, reducing memory use for long videos. The file is finalized when you stop recording or the video ends. Keep this side panel open while recording; Chrome must remain running.
